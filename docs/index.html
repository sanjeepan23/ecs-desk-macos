Features

Daily read, debug, and deploy work on ECS.

One view for each region

Clusters, services, and tasks in a tree. The overview lists the services that need attention.

Service details

Rollout progress, events, tasks, logs, metrics, and the task definition on one page.

Live logs

Tail CloudWatch Logs. Filter by level, search, pause, and load earlier lines.

Metrics

CPU and memory charts for 1 h, 6 h, 24 h, or 7 d.

Actions

Scale a service, force a new deployment, roll back, or stop a task.

Exec

Open a shell in a running container with ECS Exec.

Stopped tasks

Stopped tasks grouped by cause, such as out of memory, with advice for each cause.

Deploy watch

Follow a rollout. Get a desktop notification when it ends or fails.

Command palette

Press ⌘K to go to any cluster, service, or task.

Safety

Safe by default.

Credentials stay on your machine. The app reads your local AWS profiles.

Profiles with "prod" in the name start in read-only mode.

A destructive action on a production profile asks you to type the service name.
